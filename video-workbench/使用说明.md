# 视频工作台使用说明

## 1. 启动

在 PowerShell 执行：

```powershell
cd D:\yisho\video-workbench
.\start.ps1
```

打开 http://localhost:8765 。已有服务运行时先在原启动窗口按 Ctrl+C，等待退出后再启动，使修改生效。保持启动窗口开启。同事使用启动窗口显示的 LAN 地址访问，需位于可互通的局域网。

## 2. 制作第一条视频

1. 填写视频名称和提交人。
2. 添加至少一段视频，用上下箭头调整顺序；支持 MP4、MOV、M4V、WEBM，最多 20 段。
3. 添加一首背景音乐，单文件最多 1GB、每任务素材合计最多 4GB。
4. 粘贴最终文案。按当前估算，每个非空白字符约 0.22 秒，总时长不超过 3 分钟；文案过短无法容纳字幕动画，需要补充。
5. 选择新品上新、卖点介绍或活动促销，以及横屏/竖屏和音乐音量。
6. 默认选择“按素材顺序剪辑”，点击“开始制作”。等右侧状态变为“可下载”。
7. 点击“查看预览”，检查字幕、画面和音乐，再下载草稿包。

当前只制作字幕和背景音乐，原视频声音会静音。素材不足时会重复使用；顺序模式不会识别内容或清除画面里已有的字幕。预览是近似效果，最终效果需在剪映检查。

## 3. 导入剪映并导出

1. 在目标电脑的剪映下载“悠然体”及“放大、波浪弹入、波浪弹出”文字动画资源。
2. 完整解压下载的 ZIP。
3. 保存工作并退出剪映。
4. 右键解压后的 `Import-Draft.ps1`，选择“使用 PowerShell 运行”；也可在 PowerShell 中切换到解压目录后执行 `.\Import-Draft.ps1`，便于查看错误提示。
5. 重新打开剪映，在首页找到草稿。检查镜头、字幕、字体、动画和音乐，修改后从剪映导出最终视频。

同一草稿不能重复导入。若剪映草稿库为自定义位置，执行 `.\Import-Draft.ps1 -Store '你的草稿库绝对路径'`。如提示缺少资源，先在剪映下载所列资源再重试。

## 4. 修改、取消和删除

- “修改一版”：沿用素材，修改文案、风格、画幅或音乐音量后生成新任务，原版本保留。需要替换素材时新建任务。
- “修改后重试”：修正失败原因后重新制作；素材不完整时需重新上传。
- 上传中或排队中可以取消；制作中需等待结束。
- 删除会永久清理该任务在服务器上的素材副本、预览、草稿包和记录，其他版本及电脑上的原始素材保留。上传中先取消再删除。

## 5. 常见问题

- **需要处理**：打开任务详情查看原因。缺字体/动画时先下载资源；素材损坏时重新上传。管理员可检查 `data/jobs/<任务ID>/error.log` 和 `commands.jsonl`。
- **自动口播**：选择火山引擎口播、音色和语速，先点击“生成试听”确认声音，再开始制作。完成后任务详情可下载完整口播 WAV。待配置时请管理员设置语音 API Key 并重启。
- **AI 选项不可用**：默认不启用。管理员配置 `.env` 中的 AI 参数并重启，使用者还需勾选关键帧分析授权；会发送关键帧和文案。
- **同事无法访问**：确认使用工作机的局域网地址，工作机开机且服务运行，并检查公司防火墙的 TCP 8765 放行规则。
- **备份**：停止服务后备份整个 `data` 目录，再重启；其中包含任务数据库和素材。

环境安装和配置见 README.md。

## 页面偏好与口播回退

自动口播默认开启，可切换为不生成口播。语音 API 不可用时自动回退到字幕加背景音乐流程，任务详情会说明原因。提交人、口播开关、音色（含自定义 ID）、语速、画幅、选片方式、风格和背景音乐音量修改后立即保存在当前浏览器，下次打开自动恢复；切换口播保留当前音乐音量。
